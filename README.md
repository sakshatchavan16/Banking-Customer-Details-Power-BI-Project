# 📊 Bank Customer Details & Financial Behavior Dashboard

## 🔍 Project Overview
This Power BI dashboard provides a comprehensive analysis of bank customers, focusing on their financial behavior, loan patterns, and transaction activities. The goal of this project is to derive meaningful insights that help in better decision-making and customer segmentation.

---

## 🎯 Objectives
- Analyze customer demographics and account details  
- Understand loan distribution and customer borrowing behavior  
- Track transaction patterns and trends  
- Identify high-value customers and financial insights  

---

## 🛠️ Tools & Technologies
- Power BI  
- Data Cleaning & Transformation  
- Data Visualization  
- DAX (Data Analysis Expressions)  

---

## 📊 Dashboard Features

### 🔹 Executive Overview
- Total Loan Customers: **1.214K**
- Average Loan Amount: **₹301.56K**
- Average Transaction Amount: **₹50.20K**
- High-level KPI metrics for quick insights  

### 🔹 Customer & Account Analysis
- Customer segmentation based on demographics  
- Account type distribution  
- Monthly trends and behavior patterns  

### 🔹 Loan & Transaction Analysis
- Loan distribution across customers  
- Transaction trends over time  
- Spending and financial activity insights
